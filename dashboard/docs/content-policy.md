# 公開内容の編集方針

表示データは `src/data/portfolioData.js` に集約し、PCとスマートフォンで共通に使用します。この文書は公開用の編集方針です。本人確認の回答、原資料の転記、証書の識別情報、詳細な照合記録は含めません。

- 本人が公開を認める情報と、根拠を確認できる事実を使います。過去のインターンと現在の役職、受賞・出場・採択・研究支援・修了を区別します。
- 日付は根拠が一致する年・月の精度で記載し、証書の発行日を活動日と混同しません。
- 研究目的、実装済み機能、公開済み成果物、評価済みの効果を区別します。未確認の完成状況を「計画中」「開発中」など別の未確認状況に置き換えません。
- 数値には対象・条件・測定根拠が必要です。確認できない値は掲載しません。スキルの主観的な点数は使用しません。
- 個別成果物のリンクは実在と対応を確認し、本人のプロフィールや団体トップを成果物リンクとして代用しません。
- 原本PDF、写真・署名・印影・証書番号・生年月日、非公開の照合記録を配信素材にしません。

詳細な照合記録と本人確認表はローカルに保持し、ルートの `.gitignore` で除外します。アプリにimportしないことと、GitHubに公開されないことは別の確認事項です。公開前には `dist/` の配信物と、Gitの追跡ファイル・追加候補の両方を確認します。`.gitignore` は追跡済みファイルには効かないため、追跡状態も確認してください。

公開の承認と、個別の経歴・成果物の事実確認は別です。公開が承認されていても、根拠が未確認の具体的な記述は公開データから保留し、弱い状態表現へ置き換えません。訂正で不存在と確認された項目は、関連する説明・技術タグ・数値・リンクも含めて公開データから除去します。

公開は承認された範囲で既存の配信方式を使い、ソースの反映先と配信版の識別子、公開後の確認結果を記録します。復旧時も事実訂正と非公開資料の除外を維持し、誤った内容を含む旧版をそのまま再公開しません。
