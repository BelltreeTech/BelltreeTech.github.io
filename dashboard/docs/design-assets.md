# Open Variables のデザイン素材

紙色 `#f3f0e7`、墨色 `#1b1b18`、朱色を使い、本人の氏名と実際の研究・経験を主役にした組版です。括弧は `Future = [ ]` という本人の言葉につながる、研究・経験・考え方の紹介を切り替える枠として使います。本文は常に各章から読めます。

## フォントとアイコン

英数字には導入済み `@fontsource-variable/inter` の Latin WOFF2（48,256 bytes）を一つだけ自己配信します。バージョンは `package-lock.json` で固定。日本語には Hiragino Kaku Gothic ProN、Yu Gothic 等の端末フォントを使います。フォント取得に失敗した場合は端末の sans-serif へフォールバックします。外部フォントAPIへの通信はありません。

Interの出典は [Inter公式リポジトリ](https://github.com/rsms/inter)。導入済みパッケージの SIL Open Font License 1.1 と著作権表示を `public/font-license.txt` に同梱し、配信します。元のライセンス・フォント内部metadataを保全しています。アイコンは既存の `lucide-react`（ISC license）を使い、別サービスや有料素材を追加していません。

## 表現と公開範囲

新しい写真・成果物画像・データ図は掲載していません。括弧、罫線、色、文字の構図はインターフェースのための装飾です。研究結果や測定値として扱いません。研究・経歴の内容は `src/data/portfolioData.js` で管理し、訂正済みの内容を維持しています。

前の公開版の抽象WebPとNoto Serif JPの見出し用サブセットは、新版では参照・配信しません。原資料、試作、生成された画面モック、比較画像、非公開の確認メモはソース公開と配信物の両方から除外します。前の公開版の素材と説明は復旧可能なGit履歴とローカルの比較記録に保持します。

常時アニメーションや描画ライブラリは追加していません。焦点の切替は内容とリンクを即座に更新し、演出終了を待たずに読めます。スクロールと小さな操作表現は `prefers-reduced-motion` を尊重します。
